# Feliks & Paulina Travels

A personal travel dashboard tracking visits to 195 countries.

Features: interactive map, country tiers, wishlist, visit dates, notes and travel statistics.

Built with HTML, CSS, JavaScript and Leaflet. Hosted on GitHub Pages.

## Deploy

Enable GitHub Pages for the `main` branch (repository root). Open `index.html` through the published site.

Travel data is in `travel-data.json` and is visible publicly. Editing from the site uses a GitHub access token with `Contents: Read and write` access to this repository.
